# AI log

Záznamy práce s AI (podklad pro README → Práce s AI).

- `planovani/` – konverzace z claude.ai (projekt CLIENTELO PROJECT): koncept, texty, reklamy. Převzaté beze změny.
- `implementace/` – session z Claude Code, pojmenování `AAAA-MM-DD-tema.md` (tech-spec kap. 14). V desktopové aplikaci `/export` nefunguje: session se exportuje z aplikace (zip s transkriptem) a převádí na markdown (zprávy doslova, nástroje jen jako seznam, bez interních úvah a výstupů nástrojů).

Logy zachycují stav v době konverzace. Čísla a tvrzení v nich nejsou zdrojem pravdy: platí `data/etf.json`, `projection.ts` a `docs/decisions.md` (např. vzorec `r/12` z prvního plánování byl nahrazen efektivní měsíční sazbou).
